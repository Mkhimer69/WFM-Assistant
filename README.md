# WFM Assistant

A productivity toolkit built for Workforce Management (WFM) and Real-Time Operations teams.

WFM Assistant streamlines daily operational activities by providing a centralized workspace for workforce planning, agent management, operational communications, queue management, and scheduling workflows.

## Overview

WFM Assistant was developed to reduce manual effort, standardize operational workflows, and improve day-to-day efficiency for Workforce Management and Real-Time Analyst teams.

The application combines multiple operational utilities into a single interface, allowing teams to perform common activities without switching between several tools and spreadsheets.

---
## Project History

WFM Assistant started as a simple operational dashboard and gradually evolved through 200+ production deployments into a comprehensive Workforce Management toolkit.

Major phases included:

- Workforce communication tools
- Flex management automation
- Agent lookup services
- Webex integrations
- Verint automation
- Intraday reporting
- AHOD management
- HC approval workflows
- GitHub-driven feedback processes

The project continues to evolve based on operational needs and end-user feedback.

## Features

### AHOD Management
- Activate and remove AHOD coverage
- Session-based tracking
- Historical reporting
- Live status synchronization

### HC Planning & Queue Flexing
- Queue movement announcements
- Capacity planning support
- Buffer HC requests
- Upcoming interval planning

### HC Approval Generator
Generate Slack-ready approval requests with automatic timezone conversion.

Supported Timezones:

- CST
- Egypt Time
- IST

Example:

```text
@here Please approve 15 HC for an upcoming team meeting.

:hourglass_flowing_sand: Duration: 30 Minutes
:clock7: Window: 7:00 AM – 7:30 AM CST

Thanks in advance :ty_ty:
```
